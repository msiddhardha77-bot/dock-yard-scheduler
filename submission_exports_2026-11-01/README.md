# DockFlow Current Operational Export

This directory is a submission export of the current operational snapshot,
not a replacement for the historical accepted database. It was generated by
`scripts/export_data.py` from a disposable copy of
`full_dataset_corrected.db`; the operational source was not opened for write.

The existing exporter labels its manifest `synthetic: true` for compatibility
with generated datasets. That metadata flag does not change this export's
source classification. See `source_manifest.json`, `validation_summary.json`,
and `export_validation.json` for counts, checksums, and reference validation.

`full_dataset_corrected_current_seed.sql` is a SQLite 3 data-bearing dump.
`database/schema.sql` remains the separate schema-only DDL export.
